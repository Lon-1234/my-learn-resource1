六、字符串类型（重点）🔥
1. VARCHAR（最重要）
name VARCHAR(20)

含义：

最多存 20 个字符

例如：

long
admin
root
为什么 VARCHAR 最常用

因为：

字符串长度不固定

例如：

Tom
Alexander

长度不同。

VARCHAR 会：

按实际长度存储

节省空间。

2. CHAR
CHAR(10)

特点：

固定长度

即使：

'abc'

也会占：

10 个字符空间

一般：

性能高
但浪费空间

适合：

身份证
手机号
固定长度字段

简介
